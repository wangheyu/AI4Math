# Water Molecule Electron Density Background

## 项目概述

`water_molecule` 项目展示的是水分子电子密度场的三维交互式可视化。项目使用 `watermolecule.dx` 中的 OpenDX 体数据，通过 `electron_density_demo.py` 解析标量场，并用 Dash + Plotly 绘制电子密度等值面。

这个示例的重点不是分子动力学模拟，而是把一个三维标量场转化为可观察、可旋转、可调参数的几何对象。它适合作为三维科学可视化、体数据解析、等值面提取和交互式网页绘图的教学案例。

## 物理与化学背景

水分子由一个氧原子和两个氢原子组成，化学式为 H2O。氧原子电负性较强，会吸引成键电子，使水分子的电子分布并不均匀。这种不均匀分布与水分子的极性、氢键能力以及许多宏观性质有关。

电子密度可以理解为在空间中每一点附近找到电子的相对可能性。它是一个定义在三维空间网格上的标量函数：

```text
rho = rho(x, y, z)
```

其中 `rho` 表示电子密度，`x, y, z` 是空间坐标。电子密度较高的区域通常靠近原子核和化学键附近，密度较低的区域则远离分子主体。

## 数据格式

本项目的数据文件是：

```text
water_molecule/watermolecule.dx
```

它采用 OpenDX ASCII 格式保存体数据。文件中包含：

- 网格尺寸：`40 x 60 x 20`
- 总采样点数：`48,000`
- 网格原点：`(-1.0, -3.0, -2.0)`
- 三个方向的网格间距：`0.1`
- 每个网格点上的电子密度值

这些数据共同定义了一个规则三维网格。程序读取这些标量值后，将其恢复成三维数组，并映射到对应的空间坐标上。

## 等值面可视化

等值面是三维标量场中满足某个固定数值条件的曲面：

```text
rho(x, y, z) = c
```

其中 `c` 是用户选择的阈值。对于电子密度场来说，等值面可以显示“电子密度达到某个水平”的空间边界。调高阈值时，可见区域通常会更集中；调低阈值时，可见区域会扩展到更外层。

`electron_density_demo.py` 中提供了几个交互参数：

- `Threshold`：控制等值面的电子密度阈值
- `Shell width`：控制显示的密度壳层宽度
- `Opacity`：控制透明度
- `Colorscale`：控制颜色映射
- `Lighting`：控制光照效果
- `Camera`：控制观察视角
- `Display`：控制坐标轴和边框显示

这些控件可以帮助使用者观察同一个体数据在不同阈值、视角和光照条件下的几何形态。

## 数学与计算背景

这个项目涉及三个核心计算步骤：

1. 解析 OpenDX 文件，提取网格大小、原点、间距和标量值。
2. 将一维存储的密度数据恢复为三维数组。
3. 将三维网格点展开为 Plotly `go.Isosurface` 需要的一维顶点数组。

OpenDX 文件通常按线性顺序存储数据，而可视化库需要明确知道每个顶点的空间坐标和对应标量值。因此程序需要保证：

```text
x[i], y[i], z[i], value[i]
```

四个数组长度一致，并且第 `i` 个坐标点与第 `i` 个电子密度值对应。

## 教学意义

这个示例可以连接多个课程主题：

- 科学数据文件格式
- 三维规则网格
- 标量场与等值面
- 体数据可视化
- NumPy 数组重塑与展平
- Plotly/Dash 交互式 Web 应用

相比静态图片，交互式等值面更适合展示三维结构。学生可以通过旋转、缩放和调节阈值理解三维标量场如何变成可观察的几何曲面。

## 运行方式

推荐在课程三维可视化环境中运行：

```bash
conda activate ai4math-vis
python water_molecule/electron_density_demo.py
```

默认服务地址为：

```text
http://127.0.0.1:8053
```

也可以先运行检查模式，确认数据解析和图对象构造正常：

```bash
python water_molecule/electron_density_demo.py --check
```
