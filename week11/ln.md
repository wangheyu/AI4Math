# 阶段 5 讲稿：无监督学习

## 一、开篇：监督学习 vs 无监督学习

### 1.1 回顾我们已经做了什么

前面四个阶段，我们一直在做**监督学习**：给定图片 $x$ 和标签 $y$（这张图是数字几、是哪种服饰），训练模型预测 $f_\theta(x) \approx y$。核心公式是 Loss(pred, label)——模型的预测和人工标注的标签做比较。

监督学习很强，但它有一个根本前提：**你需要大量人工标注的标签**。ImageNet 有 1400 万张人工标注的图片，GPT 的训练语料经过了大量的人工筛选和清洗。标签是昂贵的，有些领域甚至无法获得足够标签（比如医学影像需要专家标注）。

### 1.2 阶段 5 的核心问题

**如果所有标签都拿掉，模型还能学到有用的东西吗？**

这就是无监督学习要回答的问题。无监督学习不是"没有目标"——目标仍存在，但它来自**数据本身**而非人工标注。比如：把图片压缩到 32 维再还原，还原得好不好？好就是目标。这个目标不需要任何人告诉你"这张图是 T 恤"。

### 1.3 五种方法的递进逻辑

阶段 5 设计了五个方法，它们不是并列关系，而是一条递进线：

| 方法 | 核心问题 |
|------|----------|
| PCA | 数据的内在结构长什么样？ |
| K-means | 不用标签，能把数据分成有意义的组吗？ |
| Autoencoder | 神经网络能自己学会压缩和还原吗？ |
| Denoising AE | 如果让任务更难（加噪声），学到的特征会更好吗？ |
| VAE | 能不能从"还原见过的图"升级到"创造没见过的图"？ |

每一步解决前一步的一个根本局限。下面逐一展开。

## 二、PCA：线性降维——找到方差最大的方向

### 2.1 直觉

想象 Fashion-MNIST 的 60,000 张图片，每张是 784 维空间中的一个点。这些点不是均匀分布在整个 784 维空间中的——它们集中在一个低维"子空间"附近。PCA 的问题是：**哪个方向上，数据散得最开？**

方差最大的方向 = 包含信息最多的方向。PC1 就是那个方向。然后在与 PC1 正交的所有方向中，再找方差最大的——那就是 PC2。依此类推。

### 2.2 数学

数学上，PCA 等价于协方差矩阵 $\Sigma = \frac{1}{N}X^TX$ 的特征分解。特征值 $\lambda_i$ = 该方向上的方差，特征向量 $v_i$ = 该方向本身。降维就是取前 $k$ 个特征向量做投影：$Z = XV_k$。

这里有一个重要的优化视角：PCA 最大化投影方差，同时等价于最小化重构误差 $\|X - ZV_k^T\|^2$。这个"重构误差最小化"的思路会在 Autoencoder 那里再次出现——而且是非线性版本。

### 2.3 线性性质

PCA 是线性的：每个主成分是 784 个原始像素的线性组合。降维本质上是旋转坐标系——不扭曲数据，只是换一个角度看。

**优点**：计算快（$O(d^3)$，$d=784$ 时毫秒级），结果唯一、可解释（每个主成分 reshape 成 $28\times28$ 就是一张"特征图"），无超参数（只需指定目标维度 $k$）。

**局限**：只能捕捉线性关系。如果数据分布在一个曲面上，PCA 只能在切平面方向上看——丢失弯曲结构。这正是后面需要 Autoencoder 的原因。

### 2.4 Fashion-MNIST 结果

在实际数据上：
- **2D PCA 保留 46.81% 方差**——散点图中 T-shirt/Coat/Pullover/Shirt 四类严重重叠，但鞋类（Sandal/Sneaker/Ankle boot）和衣物类自然分成两大簇。PCA 无意中学到了"鞋 vs 衣"这个粗粒度语义，虽然它完全不知道标签。
- **32D PCA 保留 82.62% 方差**——前 30-40 维贡献了绝大部分方差，边际收益之后迅速递减。这说明 Fashion-MNIST 有很强的低维结构。

选择 32 作为目标维度是合理的：既保留了大部分信息，又为后续 AE 提供了一个公平的对比 baseline。

## 三、K-means：聚类——不用标签能分组吗？

### 3.1 算法

K-means 是最经典的聚类算法。给定 $N$ 个点，要分成 $K$ 组：

1. 随机（或 K-means++ 策略）初始化 $K$ 个聚类中心
2. **分配步 (E-step)**：每个点分配给最近的中心
3. **更新步 (M-step)**：每个中心移到所属点的均值位置
4. 重复 2-3 直到收敛

目标函数是最小化组内平方和 $\sum_{k=1}^K \sum_{x \in C_k} \|x - \mu_k\|^2$。每步都使目标函数不增——算法保证收敛。但收敛到局部最优，所以实际中多次随机初始化取最佳。

### 3.2 局限

K-means 有四个关键局限：
1. **必须预设 K**——你需要提前知道有多少类。真实无监督场景不知道。
2. **假设球形簇**——用欧氏距离，隐含假设每簇是球形、等大小。
3. **线性决策边界**——簇之间由超平面分隔（Voronoi 图），无法处理嵌套或环形结构。
4. **对离群点敏感**——一个极端值可以拉偏整个中心。

### 3.3 评估

评估无监督聚类本身是难题——因为没有标签可以参考。这里我们用**外部指标**（需要真标签，但仅用于评估，聚类过程不使用标签）：

- **NMI（归一化互信息）**：衡量聚类与真标签共享多少信息。0 = 独立，1 = 完美一致。
- **ARI（调整兰德指数）**：修正随机匹配偏差。0 = 随机水平，1 = 完美匹配。ARI 比原始 RI 更诚实——不会被类别不均衡"欺骗"。

### 3.4 结果

- **像素空间 K-means**：NMI=0.51, ARI=0.35。T-shirt/Coat/Shirt 三类严重混淆，Trouser 聚类最纯。鞋类之间也有一定窜扰。
- **PCA 32D 特征上的 K-means**：NMI=0.49, ARI=0.34。仅比像素空间低 0.02——差异极小。

关键结论：**像素 vs PCA 差异极小**，说明瓶颈不在特征空间的噪声，而在 K-means 本身的线性/球形假设。T-shirt、Shirt、Pullover、Coat 这四类在像素空间中本质上相似——任何线性方法都难以分离。**需要非线性的无监督方法**——这就是 Autoencoder 登场的原因。

## 四、Autoencoder：神经网络自己"压缩-还原"

### 4.1 结构

Autoencoder (AE) 由三部分组成：
- **Encoder**：$784 \to 256 \to 64 \to 32$（压缩）
- **Bottleneck**：32 维——信息瓶颈
- **Decoder**：$32 \to 64 \to 256 \to 784$（还原）

Loss = MSE(原图, 重构图)。训练目标仅仅是"还原输入本身"——不需要任何标签。图片自己就是监督信号。

### 4.2 与 PCA 的本质区别

PCA 是线性变换：$z = Wx$。它的降维是旋转坐标系——只能在平面上找方向。

AE 是非线性变换：$z = f_\theta(x)$。ReLU 激活函数让它可以学习弯曲的流形。PCA 找的是"方差最大的平面"，AE 找的是"数据所在的曲面"。

在 Fashion-MNIST 上的 Linear Probe 对比：AE 82.25% vs PCA 81.06%。增益仅 1.2%——这说明 Fashion-MNIST 的变异以线性为主。在更复杂的数据（CIFAR-10、人脸）上，AE 的非线性优势会更显著。

### 4.3 训练过程

训练循环与监督学习完全相同（5 步），唯一的区别：

```python
for images, _ in train_loader:    # 标签被 _ 丢弃！
    optimizer.zero_grad()
    recon, z = model(images)
    loss = F.mse_loss(recon, images.flatten(1))
    loss.backward()
    optimizer.step()
```

标签被丢弃，图片自身既是输入也是监督信号——这是自监督信号设计的核心模式。

### 4.4 Bottleneck 权衡

Bottleneck 的大小是最关键的设计选择：
- **太小（如 2D）**：信息瓶颈太紧，重构模糊——但正则化强
- **32D**：平衡点——MSE 0.009，重构质量好
- **太大（如 128D）**：网络可能学会"恒等映射"——直接把输入复制到输出，latent 没有学到有意义的压缩
- **784D**：完美重构但毫无意义的压缩率 = 1

### 4.5 什么是 Latent 空间？

Latent space（潜在空间）是 AE 中 bottleneck 层的 32 维向量所在的空间。它是原始 784 维像素空间的一个**低维抽象表示**。

**直观类比：**

想象你要向一个没见过某个人的人描述这个人的长相。你不会逐像素描述一张照片——你会说"身高 175、偏瘦、戴眼镜、圆脸"。这几个关键词就是一个低维的 latent 表示——它丢弃了大量细节（像素），但保留了最核心的辨识信息。

AE 的 encoder 做的事本质上一样：把 784 个像素值压缩成 32 个"关键词"（latent 向量的 32 个分量），每个分量不是人工定义的（如"身高"），而是训练自动学出来的抽象特征。

**Latent 空间的三个理想性质：**

1. **连续性**：相似的图片在 latent 空间中距离近。一件浅色 T 恤和另一件浅色 T 恤的 latent 向量应该接近。
2. **平滑性**：在两个 latent 向量之间线性插值，解码出来的图片应该平滑过渡（一个人逐渐变成另一个人，中间过程有意义）。
3. **可解释性**：理想情况下，latent 的不同维度对应不同的语义属性（如一个维度控制"领口形状"，另一个控制"袖长"）。

**AE vs PCA 的 latent 空间：**

- PCA 的 latent 空间是在原始 784 维空间中旋转坐标系得到的**平面**。主成分方向是直线——数据必须沿着这条直线的方向变化，PCA 才能捕捉。
- AE 的 latent 空间是一个**弯曲的流形**（manifold）。ReLU 激活函数让 encoder 可以"弯折"坐标轴来贴合数据的真实形状。数据分布在曲面上，AE 的 latent 空间可以弯曲来适应它——这是 PCA 做不到的。

**为什么叫"潜在"（latent）？**

因为这个空间不是直接观测到的——你看不到一张图片的 latent 坐标。它是模型内部"发明"的表示方式，隐含在（latent in）网络的中间层。模型的输入输出都是像素，但内部用 latent 向量来"思考"。

### 4.6 Latent 空间可视化

将 AE 的 32D latent 空间用 PCA 降到 2D 可视化：同类样本自然趋向聚集，鞋类和衣物类形成两个大簇。这证明了：**单纯的重构任务确实迫使网络学到了有意义的语义结构**——尽管它从未被告知"这是 T 恤"或"这是凉鞋"。

### 4.7 AE 的局限

- **Latent 不连续**：两个样本之间的 latent 插值可能产生无意义输出
- **不能生成**：AE 只能重构见过的图，不能创造全新样本
- **对噪声敏感**：输入稍有扰动，重构可能大幅偏离

这些局限正是 Denoising AE 和 VAE 要解决的。

### 4.8 延伸讨论：Autoencoder 得到了什么？

训练完成后，AE 得到了两样东西：

**1. 一个压缩表示（Encoder）**

将任意 784 维图片映射到 32 维 latent 向量。这个 32 维向量不是随机的——同类图片的 latent 自然聚集（如鞋类和衣物类形成两个大簇）。这说明 **encoder 学到了 Fashion-MNIST 的语义结构**，尽管训练时从未见过标签。

**2. 一个重构能力（Decoder）**

从 32 维 latent 还原出 $28\times28$ 图片。MSE 仅 0.009，说明 **decoder 学会了"服饰图片长什么样"**——这不是记住训练样本，而是学到了一个从低维编码到图片的生成映射。

**本质：** 训练完的 AE 是一个 24.5 倍的有损压缩器（$784 \to 32$）。但与传统压缩算法不同，它的压缩方式**利用了数据本身的语义规律**——这正是 latent 空间出现类别结构的原因。模型不知道"这是 T 恤"，但它知道"这些图片之间相似，那些图片之间不同"。

### 4.9 延伸讨论：Autoencoder 如何做分类？

AE 本身是**无监督模型**——它只学会压缩-还原，不会直接输出类别。要做分类，有三种方式：

**方式一：Linear Probe（最简单，已实现）**

冻结训练好的 encoder，在 latent 特征之上接一个线性分类器：

```python
model = Autoencoder()
model.load_state_dict(torch.load("checkpoints/autoencoder.pt"))
model.eval()

features = model.encode(images)  # (N, 32)
clf = LogisticRegression()
clf.fit(features_train, labels_train)
acc = clf.score(features_test, labels_test)
```

实验结果：AE 32D + Linear Probe = **82.25%**（略优于 PCA 的 81.06%）。线性分类器能分好类，证明无监督特征已经将类别自然分开了。

**方式二：Fine-tuning（微调）**

在 encoder 后面接一个 `Linear(32, 10)` 分类头，然后用标签训练：

```python
class AEClassifier(nn.Module):
    def __init__(self, ae_checkpoint):
        super().__init__()
        ae = Autoencoder()
        ae.load_state_dict(torch.load(ae_checkpoint))
        self.encoder = ae.encoder
        self.classifier = nn.Linear(32, 10)

    def forward(self, x):
        return self.classifier(self.encoder(x))
```

相比从头训练，AE 预训练的 encoder 已经学到了有意义的特征结构，fine-tune 收敛更快、需要的标签更少。

**方式三：半监督场景（AE 最有价值的应用）**

标签很少，但无标签数据很多。先在所有无标签数据上训练 AE → 然后在少量有标签数据上接分类器。预训练学到的特征结构大幅降低了对标签量的需求。这是 AE 在医学影像、遥感等标注昂贵领域的核心价值。

**核心逻辑：** AE 做分类的价值不在于"AE 本身能分类"，而在于它通过重构任务学到的压缩表示已经捕捉了数据的语义结构，使得后续分类器只需很少参数和标签就能达到不错的效果。

## 五、Denoising Autoencoder：加噪声，表征更鲁棒

### 5.1 原理

去噪自编码器 (DAE) 的训练方式只有一处改变：
- **输入** = 原图 + 高斯噪声 ($\sigma=0.3$)
- **目标** = 干净的原始图像
- **模型结构** = 与普通 AE 完全相同

为什么加噪声能让表征更好？普通 AE 学到的是"记住像素"——它可以只是逐像素地复制。但 DAE 的输入被噪声污染了——模型**必须学会区分信号和噪声**。而且噪声每次都是新的随机数——模型无法"背诵"噪声模式，被迫提取本质结构。

### 5.2 直觉类比

一个好老师不会考学生做过的原题，而是考变体——检验是否真正理解。DAE 每张训练图都加了不同的随机噪声——模型永远看到"新图片"，必须学会忽略表面扰动。

### 5.3 关键认知

DAE 的测试 MSE (0.012) 比 AE (0.009) 高——因为任务本身更难。但 MSE 更高**不意味着表征更差**。恰恰相反：DAE 的 encoder 被迫学习更鲁棒的特征，对输入扰动更不敏感，学到的表示更接近数据的"不变性"（形状而非纹理）。

**重构误差 $\neq$ 表征质量**——这是无监督学习评估中最容易犯的错误。

### 5.4 自监督信号设计

DAE 是**自监督学习 (Self-Supervised Learning)** 的经典案例：
1. 不需要人工标签——pretext task（去噪）自动生成监督信号
2. "破坏-重建"范式——破坏输入，要求还原原始信号
3. 模型结构零改动——与 AE 完全相同
4. 目标决定表征质量——同样的结构，不同 pretext task 学到完全不同的特征

这个思想是当代大模型的雏形：BERT 的 masked language model（遮住词、预测词）和 GPT 的 next-token prediction（上文、预测下文）本质上都是"破坏-重建"式的自监督学习。

## 六、VAE：从重构到生成

### 6.1 核心问题

普通 AE 的 encoder 输出一个确定的向量 $z$。问题是：latent 空间是零散的——只在训练样本附近有值。两个训练样本之间的 latent 区域可能解码出无意义的噪声。你没法从 latent 空间中随机采样并期望生成有意义的图片。

VAE 的核心创新：**不学一个确定的点，而是学一个概率分布 $\mathcal{N}(\mu, \sigma^2)$**。

### 6.2 结构变化

VAE 的 encoder 输出两个向量（各 32 维）：
- $\mu$：latent 的中心位置（"最佳猜测"）
- $\log\sigma^2$：latent 的不确定范围（"我对这个猜测有多不确定"）

然后通过**重参数化技巧**采样：$z = \mu + \epsilon \cdot e^{\log\sigma^2/2}$，其中 $\epsilon \sim \mathcal{N}(0,I)$。

为什么要重参数化？因为"从分布中采样"这个操作不可导——梯度无法流过随机节点。重参数化将随机性 $\epsilon$ 与参数 $\mu, \log\sigma^2$ 分离——梯度可以正常反向传播。

### 6.3 Loss 函数

$$\mathcal{L} = \underbrace{\text{MSE}(x, \hat{x})}_{\text{重构项}} + \beta \cdot \underbrace{D_{\text{KL}}(\mathcal{N}(\mu,\sigma^2) \| \mathcal{N}(0,I))}_{\text{KL 正则项}}$$

- **重构项**：与 AE 相同——确保还原质量
- **KL 正则项**：惩罚 latent 分布偏离标准正态 $\mathcal{N}(0,I)$——把每个样本的 latent 分布"拉向"原点

KL 散度项是 VAE 能生成的关键。它有两个作用：
1. 让所有样本的 latent 分布聚拢在原点周围——整个 latent 空间被"填满"
2. 确保采样 $z \sim \mathcal{N}(0,I)$ 时，大概率落在某个训练样本的 latent 气泡内

### 6.4 $\beta$ 的权衡

$\beta$ 控制重构质量 vs 生成多样性的平衡：
- $\beta < 0.1$：重构好，latent 零散——偏向 AE
- $\beta = 0.1$：我们的选择——兼顾重构清晰度和生成能力
- $\beta = 1$：标准 VAE——偏生成
- $\beta > 1$：强正则——latent 更规整，适合解纠缠表示学习（$\beta$-VAE）

### 6.5 生成结果

训练完成后，从 $\mathcal{N}(0,I)$ 随机采样 latent，decoder 就能生成新图片。我们的 VAE 可以生成轮廓清晰的服饰图片——虽然有些模糊，但形状和类别特征明显。

Latent 空间插值：两张真实图片的 latent 之间线性插值，中间图片平滑过渡——证明 latent 空间是连续的，$\beta=0.1$ 在生成多样性和清晰度之间取得了好的平衡。

VAE 完成了从"理解数据"到"创造数据"的最后一步。它同时是降维模型、生成模型、和概率模型。

## 七、Linear Probe：如何公平比较无监督特征？

### 7.1 方法

不同无监督方法学到不同形式的"特征"——PCA 是投影矩阵，AE 是 encoder 网络，K-means 是聚类分配。如何公平比较它们？

**Linear Probe**：冻结特征提取器，在上面训练一个线性分类器 (Logistic Regression)。分类准确率 = 特征质量的代理指标。

逻辑：如果**线性**分类器就能分好类，说明无监督特征已经将不同类别自然分开了。分类器越简单，对特征质量的要求越高——这是对无监督表征最严格的测试之一。

### 7.2 结果

| 特征来源 | Linear Probe 准确率 |
|----------|-------------------|
| PCA 32D | 81.06% |
| AE 32D | **82.25%** |

AE 仅比 PCA 高 1.2%。这个结果值得深入解读。

### 7.3 为什么差距这么小？

1. **Fashion-MNIST 以线性结构为主**：前 32 维 PCA 已保留 83% 方差。剩余 17% 中非线性结构只占一部分。
2. **数据越简单，非线性优势越小**：在 CIFAR-10、人脸等复杂数据上，AE 的优势会更显著。
3. **Linear Probe 只测"线性可分性"**：AE 在重构能力、latent 空间质量、可扩展性上还有 PCA 不具备的价值。

### 7.4 核心教训

1. **简单的 baseline 往往是强 baseline**——不要跳过 PCA 直接用深度学习
2. **增益大小取决于数据复杂度**——MNIST/Fashion-MNIST 本质是"简单"数据
3. **单一指标不够**——Linear Probe 高 ≠ 特征完美。选择合适的评估指标取决于你的下游任务
4. **无监督评估本身就是开放问题**——我们用真标签做 Linear Probe，但真正的无监督场景没有标签。实践中常用下游任务性能间接评估

### 7.5 延伸讨论：为什么用线性分类器？非线性不会更好吗？

这个问题触及 Linear Probe 设计哲学的核心。

**非线性分类器（如 MLP）确实会得到更高的准确率。** 比如在 AE 32D 特征上接一个两层 MLP 分类头，准确率可能从 82.25% 提升到 85% 甚至更高。但这恰恰是问题所在。

**Linear Probe 的目的不是追求最高分类准确率——而是评估特征本身的质量。** 这个区别至关重要：

| | 线性分类器 | 非线性分类器 |
|---|---|---|
| 分类器能力 | 弱——只能画直线/超平面 | 强——可以画任意弯曲的决策边界 |
| 对特征的要求 | 高——特征必须已经线性可分 | 低——分类器可以"修正"不好的特征 |
| 反映的信息 | 特征本身的结构质量 | 特征 + 分类器的联合能力 |

**直观类比：** 评估一个学生是否真正理解了知识点。

- **线性分类器 = 选择题**：题目本身不提供任何推理空间，答对说明真的懂了。
- **非线性分类器 = 开放式论述题**：学生的推理能力（分类器）可以弥补知识漏洞（特征不好）。

如果你想知道这个学生（特征提取器）本身的水平，应该考选择题——把评判者（分类器）的能力降到最低，被测者的真实水平才能暴露出来。

**反过来说：** 如果允许分类器本身很强，那即使特征很差（比如原始像素随机投影），一个足够深的 MLP 分类器也能强行拟合出不错的准确率——但这不是因为特征好，而是因为分类器在"替特征干活"。

**Linear Probe 的哲学：** 分类器越弱，对特征的要求越高。线性分类器是最弱的非平凡分类器——这就是为什么用它来测试无监督特征。特征能通过线性分类的检验，说明无监督方法确实把数据结构学明白了。

**实践中：** 如果你的下游任务确实会用非线性分类器，那么用非线性分类器评估也是合理的。但报告结果时应该同时报告两种——线性结果说明特征的"原生质量"，非线性结果说明特征的"实用价值"。只报非线性结果而隐藏线性结果，是无监督学习论文中常见的"作弊"手段。

## 八、总结：五步递进的全景

从方法论的视角回顾五步：

1. **PCA** 问：数据结构长什么样？→ 线性旋转变换，找到方差最大的方向。最快的 baseline，81% 的 Linear Probe 来自线性结构。
2. **K-means** 问：没有标签能分组吗？→ 迭代分配-更新，最小化组内平方和。NMI 0.51，线性/球形假设是瓶颈。
3. **AE** 问：神经网络能自己压缩吗？→ 非线性 Encoder-Decoder，重构即自监督。Latent 空间出现语义结构，Linear Probe 82.3%。
4. **DAE** 问：加噪声能更鲁棒吗？→ 破坏-重建范式，区分信号与噪声。MSE 更高但表征更好——重构误差 ≠ 表征质量。
5. **VAE** 问：压缩能变成生成吗？→ 概率化 latent + KL 约束。从 $\mathcal{N}(0,I)$ 采样生成新图片——从"理解"到"创造"。

**核心递进逻辑**：线性 → 非线性 → 鲁棒 → 概率 → 生成。每一步解决前一步的一个根本局限。五步走完，模型从"理解数据"走到了"创造数据"。

**最重要的一个认知**：无监督学习不是"没有目标的学习"——目标来自数据本身。重构误差、方差最大化、聚类紧密度——这些都是不需要人工标签就可以定义和优化的目标函数。设计好"自监督信号"，神经网络就能在没有标签的情况下学到有意义的数据结构和表示。
