# 手写数字采样工具 `sampling.py`

## 功能概述

用鼠标在画布上书写数字，自动生成 28×28 灰度图片，可直接用于 MLP/CNN 模型推理和 C 语言推理程序。

核心用途：
- **交互测试**：手写一个数字，让训练好的模型实时预测
- **生成测试样本**：创建不在 MNIST 数据集中的手写数字，测试模型泛化能力
- **C 推理输入**：导出文本格式像素数据，直接作为 `mnist_mlp_infer.c` 的输入

## 使用方法

### 启动

```bash
conda run -n Teaching python sampling.py
```

需要在有图形界面（X11/Wayland）的环境下运行。WSL 下请确保已配置 X Server（如 VcXsrv）。

### 界面说明

启动后出现 280×280 的画布窗口（实际输出会降采样为 28×28），画布标题显示当前笔刷大小和下一个文件编号。

### 操作列表

| 操作 | 功能 |
|------|------|
| **左键拖拽** | 书写（白色笔触，高斯边缘衰减让笔画自然柔和） |
| **右键拖拽** | 擦除 |
| **滚轮上下** | 调整笔刷大小（4—60 px），标题栏实时显示 |
| **按 `c`** | 清空画布 |
| **按 `s`** | 保存为 28×28 PNG 图片，文件名自动编号 |
| **按 `t`** | 保存为 28×28 文本文件，文件名自动编号（兼容 C 推理程序） |
| **按 `p`** | 用已训练的 MLP 模型（`checkpoints/mnist_mlp.pt`）预测当前画布数字 |
| **按 `q`** 或关闭窗口 | 退出程序 |

### 预测输出示例

按 `p` 后终端显示：

```
========================================
  MLP 预测结果: 7  (置信度: 89.23%)
========================================
  各类别概率:
    0: ######## 0.023
    1: # 0.005
    2: ########## 0.031
    ...
    7: #################################### 0.892 <--
    ...
========================================
```

画布标题同步显示预测结果和置信度。

## 文件输出

### 自动编号

`s` 和 `t` 保存的文件名自动递增编号（从 `000` 开始），保存在 `samples/` 目录下：

```
samples/
├── drawn_000.png      # 第 1 次保存的 PNG
├── drawn_000.txt      # 第 1 次保存的文本
├── drawn_001.png      # 第 2 次保存的 PNG
├── drawn_001.txt
├── drawn_002.png
└── ...
```

每次启动程序时自动扫描已有文件，从下一个未使用的编号开始。

### PNG 格式

- 28×28 像素灰度 PNG
- 像素值范围 [0, 1]（0 = 黑色背景，1 = 白色笔画）
- 可直接用 `torchvision.datasets.ImageFolder` 或其他图片加载工具读取

### 文本格式

与 `export_mlp_params.py` 导出的样本格式兼容，可直接用于 `mnist_mlp_infer.c`：

```
# Hand-drawn digit sample
0.0000 0.0000 0.0000 ... 0.0000
0.0000 0.0000 0.0234 ... 0.0000
...
```

每行 28 个浮点数，共 28 行。用 C 推理程序测试：

```bash
./mnist_mlp_infer samples/drawn_000.txt
```

## 技术细节

### 画布与降采样

- **书写画布**：280×280 像素（10 倍于输出），提供流畅的书写体验
- **降采样**：10×10 平均池化 → 28×28
- 书写和降采样两个阶段分离，确保最终输出与 MNIST 格式一致

### 笔触渲染

- 圆形笔刷，半径可调（4—60 px）
- **高斯衰减**：笔触边缘按 $e^{-0.5 \cdot (d / (r \cdot 0.5))^2}$ 衰减，模拟真实笔迹的柔和过渡
- 多次描摹时取最大值（笔画重叠不叠加）

### 模型预测

- 加载 `checkpoints/mnist_mlp.pt`（MLP 模型，109,386 参数）
- 降采样后的 28×28 图像直接输入模型
- 输出 0—9 各类别的 softmax 概率和置信度

## 注意事项

1. **需要图形界面**：依赖 TkAgg 后端，纯终端环境无法运行
2. **需要训练好的模型**：预测功能（`p` 键）需要先运行 `mnist_mlp.py` 生成 `checkpoints/mnist_mlp.pt`
3. **画布初始为全黑**：黑色背景、白色笔画，与 MNIST 数据集风格一致（黑底白字）
4. **书写建议**：数字尽量写在画布中央，大小适中，与 MNIST 训练集的书写风格接近可获得更准确的预测
