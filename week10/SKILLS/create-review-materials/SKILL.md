# 复习资料生成器

根据用户提供的教材、讲义、习题集等资料，生成一套完整的中文 LaTeX 复习材料：
- 复习提纲（覆盖所有考点）
- 复习练习题 + 详细答案
- 100 分模拟卷 + 详细答案

## 输出规格

本技能生成 **5 份独立的 LaTeX 文件**，每份各自编译为独立的 PDF。文件按如下目录组织：

```
当前工作目录/
├── review-src/              # 所有 .tex 源文件
│   ├── outline.tex          # 1. 复习提纲
│   ├── exercises.tex        # 2. 复习练习题（仅题目）
│   ├── exercises-answers.tex # 3. 复习练习题 + 详细答案
│   ├── exam.tex             # 4. 100 分模拟卷（仅试卷）
│   └── exam-answers.tex     # 5. 模拟卷原题 + 详细答案
├── review-doc/              # 编译产物 PDF
│   ├── outline.pdf
│   ├── exercises.pdf
│   ├── exercises-answers.pdf
│   ├── exam.pdf
│   └── exam-answers.pdf
├── build/                   # latexmk 编译过程文件
├── Makefile                 # 编译控制文件
└── check-report.md          # 质量检查报告
```

**关键约束**：
- 每个 .tex 文件是**完整的、独立可编译的文档**，不依赖 `\input` 或 `\include` 引用其他生成文件
- 答案类文件（3 和 5）在文件内部包含题目原文，读者无需对照题目文件即可阅读
- 5 份文件之间内容互不重复：提纲不包含练习题，练习题不重复提纲中的知识点罗列，模拟卷题目不与练习题重复

## 前置要求

- 用户必须提供至少一份参考资料（教材 PDF、讲义、习题集等）的文件路径
- 如果用户没有明确指定输出范围，默认生成全部五份文件
- 所有 .tex 源文件写入 `review-src/`，PDF 由 Makefile 编译输出至 `review-doc/`

## 工作流程概览

```
阶段 1: 资料分析    → 提取知识点、定理、方法、符号体系
阶段 2: 提纲生成    → 按逻辑结构组织考点，生成 LaTeX 文件并编译
阶段 3: 练习题生成  → 基于考点设计练习题 + 详细答案，生成 LaTeX 并编译
阶段 4: 模拟卷生成  → 设计 100 分模拟卷 + 详细答案，生成 LaTeX 并编译
阶段 5: 质量检查    → 三轮自检：数学正确性、符号一致性、覆盖完整性
阶段 6: 最终编译    → 确保所有文件编译通过
```

## 阶段 1: 资料分析

### 1.1 阅读所有资料来源

使用 Read 工具阅读用户提供的所有 PDF 文件。

**对于常规规模的资料**（讲义、习题集等）：分页阅读，确保不遗漏内容。

**对于大部头教材**（两册共 600+ 页等情形）：采用策略性阅读方式：
- 先读完整目录，掌握全书的章—节结构
- 在关键章节（极限、微分学、积分学等核心内容）采样数页，确认符号风格和定理编号格式
- 在非核心章节（如引论、附录）仅确认标题和范围
- 生成内容时，依靠对标准课程体系的了解补全细节，而非逐页翻阅
- 最终检查阶段对照教材抽检关键定义和定理的表述

### 1.2 提取知识体系

从资料中系统提取以下内容，按章节或主题组织：

- **定义**：所有核心概念的定义，使用资料中的原始表述
- **定理/命题**：编号、名称、条件、结论，保留原始编号体系
- **公式**：重要公式及其推导条件
- **方法**：解题方法、证明技巧、计算步骤
- **反例/注记**：容易混淆的概念辨析、注意事项
- **典型例题**：资料中出现的重要例题及其解题思路

### 1.3 记录符号系统

特别注意并记录资料中使用的数学符号约定：
- 向量/矩阵的表示方式（粗体、箭头等）
- 算子符号（微分、积分、梯度等）
- 特殊集合符号（自然数集 N、实数集 R 等）
- 编号体系（章节号、公式号、定理号）

## 阶段 2: 复习提纲生成

### 2.1 提纲结构

提纲应按照以下层次组织：

```
一级：章
二级：节
三级：知识点（定义/定理/方法/注记）
```

每个知识点应包含：
- 清晰的定义或定理陈述
- 关键公式（不推导，只列结果）
- 与其他知识点的关联（如"参见定理 3.2"）
- 易错提示（如有）

### 2.2 覆盖要求

- 提纲必须覆盖资料中出现的所有考点，不得遗漏
- 对于资料中篇幅较长但考点密集的章节，应适当细分
- 对于资料中一笔带过但属于基础概念的内容，仍应列入提纲

### 2.3 LaTeX 生成

先编写 .tex 文件，再用 `latexmk -xelatex` 编译。模板结构见 `references/latex-guide.md`。

输出文件：`review-src/outline.tex`，经 Makefile 编译后 PDF 位于 `review-doc/outline.pdf`

## 阶段 3: 练习题生成

### 3.1 题目设计原则

- 练习题应覆盖提纲中的所有核心考点
- 题型以计算题和证明题为主，可包含少量填空/选择题
- 难度分两档：基础题（巩固概念，约占 60%）和综合题（跨知识点，约占 40%）
- 题目表述应与资料中的风格和符号保持一致
- 每道题应标注所考察的知识点

### 3.2 答案解析要求

答案必须：
- 写出完整的推导或计算过程，不允许跳步
- 关键步骤说明使用了哪个定理或方法
- 对易错点给出注释
- 使用与资料一致的符号

### 3.3 输出

- `review-src/exercises.tex`：仅含题目，独立编译
- `review-src/exercises-answers.tex`：独立文件，内部包含题目原文和详细答案（不依赖 exercises.tex），独立编译

## 阶段 4: 模拟卷生成

### 4.1 试卷设计

- 总分 100 分，题量适中（通常 8-12 题）
- 题型结构参考：
  - 填空题（约 15-20 分）：基础概念和简单计算
  - 计算题（约 40-50 分）：核心计算方法应用
  - 证明题（约 25-35 分）：理论理解和推导能力
  - 综合题（约 5-10 分）：跨章节综合应用
- 难度分布：基础 50%、中等 35%、较难 15%
- 必须覆盖所有主要章节，各章节分值比例与提纲中篇幅比例大致一致

### 4.2 答案要求

- 每题注明分值
- 答案详细程度同练习题阶段的要求
- 对于证明题，给出完整的逻辑链条
- 对于计算题，给出关键中间步骤和结果

### 4.3 输出

- `review-src/exam.tex`：仅含试卷，独立编译
- `review-src/exam-answers.tex`：独立文件，内部包含试卷原题和详细答案（不依赖 exam.tex），独立编译

## 阶段 5: 质量检查

这是关键阶段。完成所有 LaTeX 文件后，必须执行三轮系统检查。

### 第一轮：数学正确性

逐题逐知识点检查：
- 定理的条件和结论是否正确（特别关注条件是否完整）
- 公式推导是否有逻辑跳跃或代数错误
- 数值计算结果是否准确
- 答案是否正确且完整
- 是否存在反例（如题目的结论对于某些边界情况不成立）

**检查方法**：独立重新推导每一道题的答案，然后与已写答案比对。对于证明题，检查每一步的逻辑依据。

### 第二轮：符号与叙述一致性

- 逐一比对生成内容中使用的符号与原始资料中是否一致
- 检查定理编号、公式编号是否与资料一致
- 检查术语的中文翻译是否与资料一致
- 检查叙述风格（如使用"易得"还是"显然"）是否与资料接近

### 第三轮：覆盖完整性

- 对照提纲，逐一确认练习题覆盖了每个考点
- 对照提纲，逐一确认模拟卷覆盖了所有主要章节
- 确认模拟卷各章节分值分布合理
- 确认没有超纲内容

### 发现问题时

- **局部问题**（单题错误、个别符号不一致、编译错误）：修改对应 .tex 文件并重新编译，从当前轮继续检查即可，无需回头重做已通过的检查
- **大面积问题**（跨文件符号错误、整体结构问题）：修改后需从头重新执行三轮检查
- 直到三轮全部通过方可进入阶段 6

### 检查报告

在最终输出中附上简要的检查报告，列出：
- 每轮检查的结果（通过/发现 N 个问题并已修复）
- 最终确认的结论

## 阶段 6: Makefile 与最终编译

### 6.1 生成 Makefile

在生成第一个 .tex 文件前，先创建 Makefile（模板见 `assets/Makefile`）。Makefile 提供以下目标：

| 目标 | 作用 |
|------|------|
| `make all` | 编译全部 5 份 .tex → .pdf |
| `make outline` | 仅编译提纲 |
| `make exercises` | 仅编译练习题 |
| `make exercises-answers` | 仅编译练习题答案 |
| `make exam` | 仅编译模拟卷 |
| `make exam-answers` | 仅编译模拟卷答案 |
| `make clean` | 删除 build/ 和 review-doc/ |
| `make rebuild` | clean + all |

编译方式：`latexmk -xelatex -outdir=build -interaction=nonstopmode -halt-on-error`，PDF 输出至 `review-doc/`，过程文件留在 `build/`。

### 6.2 编译验证

所有 .tex 写入完成后，运行 `make all` 确保全部编译通过，无错误（warning 可忽略但应记录）。

如果编译失败，根据错误信息修正 .tex 文件，然后重新运行 `make all` 直到通过。

## 灵活执行

根据用户指令，可以：
- 只生成提纲（跳过阶段 3、4）
- 只生成练习题（跳过阶段 2、4）
- 只生成模拟卷（跳过阶段 2、3）
- 只生成答案文件（基于已有的题目文件）
- 一次性全部生成（完整流程）

如果用户说"全部生成"或未明确指定范围，执行完整流程。

## LaTeX 格式规范

详见 `references/latex-guide.md`。关键要点：
- 文档类：`ctexart`，12pt，a4paper
- 核心宏包：amsmath, amssymb, amsthm, mathtools, bm, physics, esint, booktabs, enumitem, geometry
- 定理环境：使用 `\newtheorem` 定义定理、定义、例题、注记等环境
- 中文排版：使用 ctex 提供的字体和排版设置
- 数学模式内的中文使用 `\text{}` 包裹

## 重要注意事项

- 所有数学公式必须仔细检查，确保在 LaTeX 中正确编译
- 中文标点（顿号、书名号等）在 LaTeX 中需要特殊处理或使用 ctex 的默认支持
- 图片/图表：如果资料来源中有重要图表，在提纲中描述，不用重新绘制
- 如果资料来源中存在明显的印刷错误，在提纲中标注但不修正（保持与教材一致）
- 生成的 LaTeX 文件应在注释中标注对应资料来源的章节/页码，便于追溯
