## 关键发现

1. **AMG 预处理 14.5x 减少迭代**：247 → 17，且收敛至 1e-9 而非 1e-6
2. **AMG CUDA 求解 25.3x 快于 CPU**：64ms vs 1626ms
3. **MKL 比 OpenBLAS 快 13-18%**：在纯 BLAS 场景下 MKL 单线程实现更优
4. **GPU 纯 CG (cuBLAS) 性价比极高**：172ms 完成 CPU 2536ms 的工作（14.7x）
5. **IC(0) GPU 加速比下降**：SpSV 三角求解的 GPU 利用率不如 SpMV（5.2x vs 14.7x）
6. **AMG 收敛精度远优于 IC(0)**：1e-9 vs 1e-5，差距 4 个数量级

## 编译关键点

- AMGCL CUDA 必须用 **nvcc** 编译（Thrust/CUB 兼容性）
- GPU 目标的 `.o` 文件必须用 **nvcc 统一编译**（g++ 和 nvcc 混合 `.o` 链接会产生堆损坏）
- IC(0) 使用 Eigen 的 `IncompleteCholesky` + `NaturalOrdering` + `Lower` + shift=1e-4
